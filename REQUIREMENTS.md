# Соответствие требованиям преподавателя

| Требование | Реализация в проекте | Что показать |
| --- | --- | --- |
| Сборочный make-файл | `makefile` с целями `all`, `check`, `docx`, `figures` | Команду `make docx` |
| Markdown в нескольких файлах | Девять файлов в `md/`, порядок задаёт `contents` | Разделы и файл `contents` |
| Оглавление | `table-of-contents: true` в `defaults.yaml` | Автоматическое оглавление Word |
| Формулы LaTeX | Три отдельные формулы и обозначения в `md/07-supplement.md` | Исходник `$$ ... $$` и уравнения Word |
| Рисунки | Схема в SVG и PNG, подключённая из Markdown | Рисунок 1 и файлы в `images/` |
| Таблицы | Markdown-таблица условного ранжирования | Таблицу 1 в исходнике и Word |
| Список литературы | `bibliography.bib`, `numeric-ru.csl`, цитирования `[@ключ]` | Десять источников и ссылки в тексте |
| Автоматическая генерация результата | Pandoc и Python, команда `make docx`, workflow GitHub Actions | `build/corporate-search.docx` |

Выбран формат **DOCX**. По условию достаточно одного из форматов PDF, DOCX
или статического сайта. Схема автоматически пересоздаётся скриптом
`tools/draw_search_pipeline.py`. Сборка проверяет наличие нескольких исходников,
формул LaTeX, изображения, Markdown-таблицы и всех цитируемых источников.

Формулы, схема и таблица находятся в отдельном дополнении к статье.
Они добавлены для семестрового проекта и не обозначаются как часть
оригинальной публикации 2024 года. Указание фамилии в исходном PDF
подтверждается на странице 28 файла, соответствующей странице 16 журнала.
